# HQ desktop app releases

This repository hosts the installers and update files for the HQ desktop app. It contains no source code.

Download HQ from [hqforwork.com/install](https://hqforwork.com/install), or pick a file from the [latest release](https://github.com/indigoai-us/hq-desktop-app/releases/latest).

Installed copies of HQ check this repository for updates on their own. You do not need to do anything here.
