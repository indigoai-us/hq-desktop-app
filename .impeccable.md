# Design Context

## Users

HQ operators who move between many local Claude and Codex conversations. They need to recognize, reopen, and continue work without understanding provider storage or process state.

## Product Character

Calm, precise, compact, and tool-like. The interface should feel native to a focused desktop work environment: dark, restrained, information-dense, and direct.

## Aesthetic Direction

Follow the existing HQ desktop visual system and the Codex conversation-list reference supplied by the user. Prefer one clear hierarchy, quiet metadata, background-only selection, and minimal status decoration. Avoid decorative chrome, oversized typography, gradients, and ornamental effects.

## Interaction Principles

- A conversation is one object whether it is currently running or stored on disk.
- Clicking a conversation opens it; process startup and resume mechanics stay invisible.
- Preserve provider titles and sort by recent activity so recognition is immediate.
- Long history is progressively loaded in bounded pages without moving the reader's scroll position.
- Keep status secondary to the conversation title; only surface it when it changes what the user can do.
